# ❌⭕ Tic Tac Toe (Jogo da Velha em Python)

[![Python](https://img.shields.io/badge/Python-3-3776AB?style=for-the-badge&logo=python)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](#)

Implementação clássica e elegante do jogo da velha desenvolvida em **Python** para execução em terminal.

---

## 📌 Sobre o Projeto

Projeto com foco em lógica de programação, manipulação de matrizes e tratamento de fluxo de jogo. Permite partidas entre dois jogadores com interface limpa em linha de comando, detecção automática de vitórias (linhas, colunas, diagonais) e empates (*velha*).

## 🚀 Funcionalidades

- 🎮 **Tabuleiro 3x3 Interativo:** Visualização formatada do estado atual do jogo a cada rodada.
- ✅ **Validação de Jogadas:** Tratamento de entradas inválidas ou posições já ocupadas.
- 🏆 **Verificação Automática de Vitória:** Checagem imediata de condições de vitória ou empate.
- 🔄 **Replay:** Opção para reiniciar uma nova partida ao final do jogo.

## 🛠️ Tecnologias Utilizadas

- **Python 3** puro (sem dependências externas)

## ⚙️ Como Executar Localmente

```bash
git clone https://github.com/IuryAlmeidaDev/tic-tac-toe.git
cd tic-tac-toe
python app.py
```
